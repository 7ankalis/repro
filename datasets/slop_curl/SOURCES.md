# Sources — datasets/slop_curl

All reports in this folder come from **Daniel Stenberg's public gist** cataloguing AI-slop security
reports submitted to curl:

- https://gist.github.com/bagder/07f7581f6e3d78ef37dfbfc81fd1d1cd
  ("AI slop security reports submitted to curl", by Daniel Stenberg / curl maintainer, @bagder)

Every report listed in that gist was classified by the curl security team as AI-generated slop and was
later publicly disclosed on HackerOne. Each report's original text was written by its reporter and
disclosed publicly through HackerOne; we reproduce it here (with reporter identities scrubbed) only as
evaluation input for Repro.

Background reading by Daniel Stenberg on the AI-slop problem in curl's bug bounty program:

- https://daniel.haxx.se/blog/2024/01/02/the-i-in-llm-stands-for-intelligence/
- https://daniel.haxx.se/blog/2025/07/14/death-by-a-thousand-slops/
